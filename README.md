### Часть 5. Анализ ошибок компилятора

| Фрагмент | Ошибка | Почему возникла и как исправить |
| :--- | :--- | :--- |
| **A** | `Type 'string' is not assignable to type 'number'.` | Переменная `count` сгенерировалась с типом `number`. Передать туда строку не выйдет.<br>**Как починить:** передавать число (`count = 10;`) или сразу сделать union-тип `number \| string`. |
| **B** | `Expected 2 arguments, but got 1.` | Функция `add` ждет 2 аргумента, а мы передали только один.<br>**Как починить:** дописать второй аргумент при вызове (`add(2, 3);`) или задать ему значение по умолчанию (`y: number = 0`). |
| **C** | `Type 'null' is not assignable to type 'string'.` | Из-за включенного `"strict": true` работает `strictNullChecks`, поэтому `null` нельзя записать в `string`.<br>**Как починить:** добавить union `let name: string \| null = null;` либо просто отдать пустую строку `""`. |
| **D** | `A function whose declared type is neither 'void' nor 'any' must return a value.` | Указали, что функция возвращает `string`, но забыли про `return`.<br>**Как починить:** дописать `return "Привет, " + name;` или поменять тип возвращаемого значения на `void`. |

### Часть 6. Ответы на вопросы для самопроверки

1. **Что такое статическая типизация и какие преимущества она даёт?**
   Это когда типы проверяются еще до запуска кода — на этапе компиляции. Из плюсов: ошибки ловятся прямо в процессе написания, нормально работает автодополнение в VS Code и код становится понятнее.

2. **Что такое вывод типов (type inference)? Когда лучше указывать аннотацию явно?**
   Это когда TS сам догадывается, какой тип у переменной, глядя на то, что в нее записали при создании. Явно типы лучше писать на параметрах и возвращаемых значениях функций, а также если переменная создается пустой или может менять тип.

3. **За что отвечает `"strict": true` в `tsconfig.json`?**
   Включает сразу целый набор жестких проверок (например, запрещает неявный `any` и не дает подсовывать `null` / `undefined` куда попало).

4. **Как скомпилировать проект и запустить результат?**
   Сначала запускаем `npx tsc` (код собирается в `./dist`), потом выполняем получившийся файл через Node.js: `node dist/index.js`.

5. **Почему `null` нельзя присвоить переменной типа `string` при `strictNullChecks`? Как правильно это сделать?**
   Потому что в строгом режиме `null` — это отдельный тип, а не часть строки. Чтобы разрешить `null`, нужно использовать объединение: `let userName: string | null = null;`.

6. **Чем `void` отличается от `undefined` в контексте возвращаемого типа функции?**
   `void` говорит, что функция ничего не возвращает и результат нас не волнует. А с `undefined` компилятор будет требовать написать явный `return undefined;`.

7. **Какую роль играют опции `rootDir` и `outDir` в `tsconfig.json`?**
   `rootDir` задает папку с исходниками (`./src`), а `outDir` указывает, куда компилятор должен складывать готовые `.js` файлы (`./dist`).
